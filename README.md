# Primitive DB

Консольная база данных на Python. В ней можно создавать таблицы со столбцами
типов `int`, `str` и `bool`, добавлять строки, искать их по условиям,
обновлять и удалять. Программа хранит схемы в `db_meta.json`, а строки каждой
таблицы в отдельном файле `data/<имя_таблицы>.json` в каталоге запуска.
Для одного каталога данных запускайте один экземпляр приложения.

## Установка и запуск

Для запуска нужны Python 3.12 и uv. Из корня проекта выполните:

```sh
./run.sh
```

Скрипт устанавливает зависимости, собирает пакет и запускает базу данных.
Данные сохраняются в каталоге проекта.

Если используете Poetry 2:

```sh
poetry install
poetry run database
```

## Управление таблицами

| Команда | Действие |
| --- | --- |
| `create_table users name:str age:int is_active:bool` | Создать таблицу. Столбец `ID:int` добавляется автоматически. |
| `list_tables` | Показать имена таблиц. |
| `info users` | Показать схему таблицы и число строк. |
| `drop_table users` | Удалить таблицу вместе с её строками. |
| `help` | Показать справку. |
| `exit` | Закрыть консоль. |

## CRUD-операции

| Команда | Действие |
| --- | --- |
| `insert into users values ("Сергей", 28, true)` | Добавить строку. |
| `select from users` | Показать все строки. |
| `select from users where age = 28` | Показать строки, подходящие под условие. |
| `update users set age = 29 where ID = 1` | Изменить значения в строках, подходящих под условие. |
| `delete from users where ID = 1` | Удалить строки, подходящие под условие. |

В `insert` указывайте по одному значению для каждого столбца схемы, кроме
`ID`. Программа вычисляет `ID` по максимальному идентификатору в таблице.
Строки заключайте в кавычки, логические значения вводите как `true` или
`false`. В `set` можно указать несколько присваиваний через запятую. Если
условий в `where` несколько, строка должна подходить под каждое из них.

Перед `delete` и `drop_table` программа запрашивает подтверждение. Введите
`y`, чтобы выполнить операцию. Любой другой ответ отменяет её. При ошибке
программа выводит причину и снова предлагает ввести команду. Для `insert` и
`select` консоль показывает время выполнения функции. Повторный `select`
по тем же строкам и условию использует кэш совпадений.
